# LeetCode Practice

A collection of LeetCode problem solutions in Python for educational purposes.

## Project Structure

```
leetcode_practice/
├── problems/          # Problem solutions
│   └── two_sum.py     # LeetCode #1: Two Sum
├── tests/             # Unit tests
│   └── test_two_sum.py
└── README.md
```

## Running Tests

```bash
# Run all tests
python -m pytest tests/ -v

# Or using unittest
python -m unittest discover tests -v
```
